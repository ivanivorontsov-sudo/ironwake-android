# legacy-webview

Прежний Android-клиент: Kotlin `MainActivity` + полноэкранный WebView
(`assets/hangar.html` на Three.js). Сохранён для истории и отладки протокола.

Боевой клиент переехал на Unity URP: см. `../unity/Ironwake/` и корневой README.

## Сборка

GitHub Actions: `.github/workflows/build-legacy-apk.yml` (working-directory `legacy-webview`).

Локально: Android Studio → Open `legacy-webview/` → Run.
